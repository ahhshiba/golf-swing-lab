# i18n and units (owner: foundation, PRODUCT-SPEC §3; FROZEN in drop 1)

Locales: `zh-Hant` (primary and fallback) and `en`. Code: `app/src/i18n/index.js` (runtime) and
`app/src/i18n/units.js` (display units). Catalogs: `app/i18n/<locale>/<namespace>.json`. Tests:
`tests/unit/i18n.core.test.mjs`, `tests/unit/i18n.catalogs.test.mjs`, `tests/unit/units.test.mjs`.

## 1. Catalog files

- One file per namespace and locale: `app/i18n/zh-Hant/setup.json`, `app/i18n/en/setup.json`.
- Keys inside a file have **no** namespace prefix and may be dotted: file `setup.json`, key `step.level.title`, full key
  `setup.step.level.title`. Nested objects are flattened with dots, so `{"step": {"level": {"title": "…"}}}` is the same.
- Params: `{name}`. A number param is formatted for the locale (integers as `1,500`, others up to 3 decimals). An
  unknown param stays visible as `{name}`.
- Plurals: the value is an object keyed by `Intl.PluralRules` category. zh-Hant uses `other` only, en uses `one` and
  `other`. `plural(key, n)` = `t(key, { n })`. Example: `"shots": { "one": "{n} shot", "other": "{n} shots" }`.
- Translator notes: a sibling key `<key>._context` (string). Never shown and stripped by the build.
- Both locales MUST have the same keys and the same placeholder set per key.
- Copy rules (§2.4): no spec ids (`P12`, `C3`, `K1`), no `UPPER_SNAKE` codes, file or script names, `sha256`,
  `golden`, `GolfDB`, `tcn`, raw ids. No full-width bracket at the start of an option label.
- Namespaces and owners are listed in `app/i18n/namespaces.json`. A package edits only its own namespaces, in both
  locales:

| owner | namespaces |
|---|---|
| foundation (A) | `app common screen nav unit validity view mode club event metric reason error a11y time` |
| practice (B) | `onboarding home venue setup calib live bay health camera` |
| results (C) | `import shot replay history compare label teach export` |
| platform (D) | `session storage diag update offline` |
| events (E) | `model events` |
| trust (F) | `settings about privacy help legal licence` |

A namespace listed there whose file does not exist yet is skipped by the loader, so a package can add its file at any
time without touching `namespaces.json`.

## 2. Loading

- `scripts/build.mjs` merges each locale into `dist/i18n/<locale>.json` (full keys, sorted, `_context` removed,
  compact JSON). Both files are in the shell precache. The namespace source files are not copied to `dist/`.
- The loader fetches `<base><locale>.json`. When that fails (dev server on `app/`, unit tests) it fetches
  `<base>namespaces.json` and then `<base><locale>/<ns>.json` for every listed namespace. `base` defaults to the
  `app/i18n/` (or `dist/i18n/`) folder next to the module, derived from `import.meta.url`.
- zh-Hant is always loaded (fallback). The active locale is loaded on top of it.
- Nothing throws. Without any catalog `t()` returns the key.

## 3. Runtime API (`app/src/i18n/index.js`)

```js
await initI18n({ locale = 'auto', fetchImpl = fetch, base, languages })  // -> 'zh-Hant' | 'en'
t(key, params = {})            // active → zh-Hant → key; a missing key is reported once to onMissing listeners
has(key)                       // boolean
getLocale()                    // 'zh-Hant' | 'en'
await setLocale(locale)        // loads the catalog, sets <html lang>, notifies listeners (always, even if unchanged)
onLocaleChange(fn)             // fn(locale, previous) -> unsubscribe
resolveLocale(pref, languages) // pure: pref wins; zh-TW/HK/MO/Hant*/CN/Hans* → zh-Hant; en* → en; else en
plural(key, n, params)         // = t(key, { ...params, n })
list(items, type)              // Intl.ListFormat, 'conjunction' | 'disjunction' | 'unit'
fmtNum(x, { digits = 0, sign = false })   // locale digits, U+2212 minus, never "−0"; digits null = up to 3; NaN → '—'
fmtDateTime(iso, { date, time })          // local time zone, dateStyle medium / timeStyle short; bad input → '—'
fmtDate(iso), fmtTime(iso), fmtRelativeDays(n)   // fmtRelativeDays(-1) → 'yesterday' / '昨天'
msg({ code, params })          // = t(code, params); a string passes through; null → ''
```

Additive helpers (not frozen): `setCatalog(locale, flat)` (unit tests: install a catalog without fetching),
`missingKeys()`, `onMissing(fn)`, `intlLocale()` (`zh-Hant-TW` / `en-US`), `flattenNamespace(ns, obj)`, `LOCALES`.

Unit tests of a package: either `await initI18n({ fetchImpl: fsFetch, base: 'mem:/' })` with a file-system fetch
rooted at `app/i18n` (see `tests/unit/i18n.core.test.mjs`), or `setCatalog('zh-Hant', {...}); await initI18n({
locale: 'zh-Hant', fetchImpl: null })`.

### App wiring (`app/src/main.js`)

- Boot: `initI18n({ locale: settings.locale })` before any screen mounts. `settings.locale` is `'auto' | 'zh-Hant' |
  'en'` (`session/settings.js`).
- `index.html` static text carries `data-i18n="<key>"` (text) and `data-i18n-aria-label="<key>"`; main.js applies them
  at boot and on every locale change.
- On `setLocale()`: `<html lang>` changes, static text is re-applied, the current screen's `show(params)` runs again,
  `document.title = t('screen.<id>.title') + ' – ' + t('app.name')`.
- Missing keys go to diag record `i18n.missing` (list, max 200).
- `app.t`, `app.locale()`, `app.units()`, `app.screenTitle(id)` are on the app object.
- To switch language from a screen: `app.updateSettings(saveSettings({ locale }))` then `await setLocale(locale)`.

## 4. Pure modules emit codes

Pure modules return `{ code, params }` message objects, never prose. The UI renders them with `msg(m)` or
`t('<ns>.' + code, params)`. `store.status` is `{ code, params } | null` (main.js renders it with `msg()`; a legacy
string still shows as it is).

- Reason codes: `RC.<NAME>` from `contract/reason-codes.js`; UI text `t('reason.<NAME>.short')`, `.long`, `.fix`
  (`.fix` only where there is something the user can do; check with `has()`). `reason-codes.js` holds codes
  only (`REASON_CODE_LIST`; `REASON_CODES` = `RC` = `{ NAME: 'NAME' }`); `describe()` is removed (PRODUCT-SPEC §3.4).
  The contract's description of a code is the zh-Hant `reason.<NAME>.long` (scripts/check_contract.mjs checks it exists,
  is Chinese and has no Simplified-only characters).
- Error codes: worker `ERR` (`workers/protocol.js`) plus `APP_ERROR_CODES` (`contract/reason-codes.js`, §8.0.7:
  `QUOTA_EXCEEDED ANALYSIS_TIMEOUT WORKER_CRASHED WORKER_UNAVAILABLE FILE_TRUNCATED REPO_UNAVAILABLE CAMERA_DENIED
  CAMERA_BUSY CAMERA_MISSING`). UI text `t('error.<CODE>', params)` and optional `t('error.<CODE>.fix')`.
  `ui/format.js` `errorText(e)` / `errorFix(e)` do this for an Error with `.code` (and `.params`).
- Metric text: `t('metric.<id>.label' | '.short' | '.meaning' | '.range' | '.term')`. Clubs `t('club.<type>')`, views
  `t('view.<id>')`, modes `t('mode.<id>')`, events `t('event.<id>')`, validity `t('validity.<v>')`
  (`validity.not_measurable` for any null validity without its own word).
- Exports (JSON/CSV) keep codes and English column ids, never localized text.

To add a reason code: follow docs/contract.md §9, then add `reason.<NAME>.short` and `.long` (and `.fix` if useful) to
both `app/i18n/*/reason.json`. Other packages send the wording to foundation in their report.

## 5. Units (`app/src/i18n/units.js`)

Storage stays SI. `settings.units = { distance: 'yd'|'m', speed: 'mph'|'m/s'|'km/h', body: 'cm'|'in',
clubLength: 'in'|'m', height: 'cm'|'ftin' }`. Defaults (§10): `{ yd, mph, cm, in, cm }`; first run on `en-US` (or bare
`en`): body `in`, height `ftin`.

```js
fmtMetric(metric, units, { id })  // -> { value, unit, ci, text, digits }; id (or metric.id) picks body vs distance
fmtQuantity(si, kind, units, { digits })  // kind: distance|speed|body|clubLength|height|s|deg|pct|ratio
convert(x, from, to)              // m yd cm in ft | m/s mph km/h (aliases mps kmh); throws on unknown/mismatched units
toSI(x, unit)                     // = convert(x, unit, SI unit of that dimension)
parseInput(text, unit)            // -> SI number | null: '1,5', ' 37.5 ', "5'10\"", '5 ft 10 in', '5′10″' (unit 'ftin')
parseLength = parseInput
unitLabel(unit)                   // t('unit.<id>') (yd → 碼 / yd), else the symbol; ratio → ''
metricKind(id, unit), defaultUnits(languages), normalizeUnits(u), DEFAULT_UNITS, UNIT_CHOICES, BODY_METRIC_IDS
```

Factors: 1 m = 1.09361 yd = 100 cm = 39.3701 in; 1 m/s = 2.23694 mph = 3.6 km/h. CI = half width of `ci95`, else
`1.96 × sigma`, scaled by the same factor; `ci` is `null` when absent or when it rounds to 0 at the display digits.
Digits: carry yd/m 0; mph 1, m/s 1, km/h 0; body cm 1, in 1; club length in 1, m 2; s 2; ratios 2; deg 0; % 0.
Body-unit metrics: `head_sway_x_m head_lift_z_m head_depth_y_m hand_plane_dev_m early_extension_m`.
`text` joins with a space (`139 ± 2 yd`), except `°` and `%` (`−3°`, `41 ± 4%`).
Thresholds in copy are params formatted by the caller with `fmtQuantity` in the user's units.
